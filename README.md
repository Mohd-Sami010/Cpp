# C++ Programs

## Assignments

### Assignment 1 : Linear Search, Binary Search and Direct Search.

Write a program to implement Linear Search, Binary Search, and Direct Search on a structured array of students containing live data such as Name, Enrollment Number, and Marks. Use the clock function to calculate the number of clock pulses/clock cycles taken by each search algorithm. Plot a graph showing the number of clock cycles taken by Linear Search, Binary Search, and Direct Search with respect to the size of the array.
